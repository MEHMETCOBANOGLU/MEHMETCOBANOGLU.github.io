# Mehmet Çobanoğlu · Portfolio

Kişisel portfolyo sitem — React + Vite ile geliştirildi.

🔗 **Canlı:** https://mehmetcobanoglu.github.io

## Özellikler

- Koyu (siyah / kırmızı) ve açık (kırık beyaz / kırmızı) tema
- Kaydırdıkça masadan uzaklaşan animasyonlu geliştirici silueti
- GitHub repolarının canlı olarak listelenmesi
- Tamamen responsive tasarım

## Geliştirme

```bash
npm install
npm run dev
```

İçerik `src/data.js` dosyasından düzenlenir. `main` dalına yapılan her push, GitHub Actions ile otomatik olarak GitHub Pages'e yayınlanır.
